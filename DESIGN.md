# Halamanku Design Direction

## Product Character

Halamanku is a calm, precise microsite builder. The product UI stays neutral so
the pages its customers create can carry the expression.

## Visual Rules

- Use neutral surfaces for most of the interface and purple only for primary
  actions, active states, and intentional emphasis.
- Prefer spacing, type hierarchy, borders, and alignment over gradients,
  glows, glass effects, or ornamental illustrations.
- Use 12px radii for controls and 16px for larger surfaces. Avoid rounding
  every element into a pill.
- Keep shadows subtle and reserve them for floating UI such as menus and
  dialogs.
- Do not invent testimonials, metrics, or claims.

## Typography And Motion

- Use Geist for product UI. Use regular, medium, and semibold weights only.
- Use 14px for controls, 16px for body copy, 32-40px for section headings,
  and 56-64px for landing-page hero copy.
- Motion is functional: 150-400ms opacity and 6-10px movement. Respect
  reduced-motion preferences. Never use bounces, looping decoration, glows,
  or large scale effects.

## Public Themes

- Canvas: warm off-white, dark text, purple accent, soft rhythm.
- Ink: dark surface, off-white text, sharper geometry.
- Editorial: warm cream, optional serif headings, generous spacing.
- Mono: black, white, and gray only.
